## 요약

- 긍정 결함 10건: 긍정 의미 표현이 키워드 사전에 없어 중립으로 분류된다.
- 부정 결함 10건: 부정 의미 표현이 키워드 사전에 없어 중립으로 분류된다.
- 중립 결함 10건: 단순 부분 문자열 매칭으로 UI 용어, 정책명, 문서명 등 중립 문맥이 긍정/부정으로 오탐된다.
- 공통 근본 원인: 감정 분석이 키워드 포함 여부만 확인하며, 키워드 누락과 문맥 오탐을 보정하는 규칙이 없다.
